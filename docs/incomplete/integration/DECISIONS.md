## The standing rule for every later owner call

When a session meets a question that the process says is the owner's, it decides by this order and does not ask: first, the choice that prevents a silent failure (a wrong result that passes every gate); second, the choice that keeps work landing without the owner; third, the choice that adds the least code and process. It records the decision with its reversal where the owner will see it (the ledger or the item file's close-out) and continues. It asks the owner only for an action no session can take: a password, a device, a purchase, or a change to a file the owner's rules say only the owner edits (`~/.claude/rules/*.md` and the frozen `standard/` content).
